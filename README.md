# Create 1.7.10 Unofficial

An unofficial, source-based reverse port of Create 6.0.8 to Minecraft 1.7.10.

The authoritative upstream baseline is Create tag [`mc1.20.1-6.0.8`](https://github.com/Creators-of-Create/Create/tree/mc1.20.1-6.0.8), by simibubi and the Create contributors. Create is distributed under the MIT License; its original license is preserved in [`upstream/create-mc1.20.1-6.0.8/LICENSE.md`](upstream/create-mc1.20.1-6.0.8/LICENSE.md).

This project is unofficial and is not endorsed by the upstream Create team. See [`PRD_UPSTREAM_PORT.md`](PRD_UPSTREAM_PORT.md) for the development scope and [`porting/README.md`](porting/README.md) for the block-by-block workflow.
